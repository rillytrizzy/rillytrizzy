## 4. NAMING CONVENTION

**Decision: Underscore convention for all Agent network accounts. No separator for rillytrizzy.**

| Handle | Convention | Status |
|---|---|---|
| agent_maxxing | underscore | Active |
| agent_afterhours | underscore | Active |
| agent_pastforward | underscore | Reserved |
| agent_viral | underscore | Reserved |
| agent_trending | underscore | Reserved |
| rillytrizzy | none | Active |

**Why underscore wins for the network:**

1. **Network identity signal** — `agent_[niche]` reads as a system. Followers who discover one account recognize the namespace and find the others. The underscore makes the network legible at a glance.
2. **Readability at scale** — `agent_pastforward` is immediately parseable; `agentpastforward` requires the reader to do the parsing. Longer handles amplify the underscore advantage.
3. **Platform norms** — Instagram and TikTok have strong underscore conventions. The readability cost on X is real but tolerable.
4. **Discoverability** — The visual break between "agent" and the niche word aids search parsing across all platforms.

**Why no separator for rillytrizzy:** It is a personal name, not a namespace. `rillytrizzy` runs naturally as a single compound word. The founder account does not join the network separator convention.

**Fallback if primary handle is taken:** Use dot (`agent.maxxing`). Never use underscore variants as fallback — the convention must be consistent across the network.

## 8. AUTOMATION ARCHITECTURE

**Goal:** Input a video URL → output platform-ready clips, captions, hashtags, and scheduled posts for at least two accounts with minimal manual effort.

### Pipeline

```
VIDEO URL INPUT
      │
      ▼
[1] DOWNLOAD
    yt-dlp — supports YouTube, TikTok, Twitch, Kick, Instagram
      │
      ▼
[2] CLIP EXTRACTION
    ffmpeg + scene detection (PySceneDetect or silence-based splitting)
    Output: N clips, 15–90 seconds each, auto-cropped to 9:16
      │
      ▼
[3] TRANSCRIPTION + CAPTIONS
    OpenAI Whisper (local) or Whisper API
    Output: SRT/VTT per clip
    Burn captions into video (ffmpeg) or export as caption file
      │
      ▼
[4] METADATA GENERATION (LLM)
    Input: transcript + target account niche profile
    Output per clip:
    - Hook line (first 3 seconds of caption)
    - Caption body (150–300 chars)
    - Hashtag set (niche-specific, 5–10 tags)
    - Account assignment (classifier routes to correct Agent account)
    - Platform variant (TikTok vs. Reels vs. Shorts formatting)
      │
      ▼
[5] HUMAN REVIEW (required — see governance section below)
      │
      ▼
[6] PACKAGE + SCHEDULE
    Organize output by account (agent_maxxing/, agent_afterhours/, etc.)
    Push to scheduling tool (Buffer, Later, or direct API)
    Output manifest: JSON file with clip path, caption, hashtags, platform, scheduled time
```

### Account-Aware Routing

The LLM step includes a routing classifier. Each clip is tagged with an account assignment:

```
Given: transcript excerpt + source context
Classify into: [agent_maxxing, agent_afterhours, agent_pastforward, agent_viral, agent_trending]
Output: account assignment + confidence score
```

Low-confidence clips are flagged for human review before scheduling. Only ACTIVE accounts receive auto-scheduled content.

### Existing Infrastructure

The `scraper.py` in this repository already scrapes trending clips from Twitch, Kick, and YouTube with view count ranking — this is the source discovery front-end. The pipeline above is the processing back-end. Together they form the full content engine.

### MVP Scope (Two Accounts)

For MVP with agent_maxxing and agent_afterhours running:
1. Scraper identifies top clips filtered by niche (game/category filter)
2. yt-dlp downloads source videos
3. ffmpeg extracts best 30–60s clips in 9:16
4. Whisper transcribes
5. LLM generates caption + hashtags with account-specific prompt
6. Human reviews and approves
7. Output folder organized by account, handed to scheduler

## 9. AUTOMATION GOVERNANCE

The automation system may:

- Download source content
- Generate clips
- Reframe video
- Generate captions
- Generate hashtags
- Categorize content
- Route content to accounts
- Prepare scheduled uploads

The automation system may NOT automatically publish content without approval.

Human approval is required for:

- Copyright-sensitive content
- Music licensing issues
- Political content
- Brand sponsorship content
- Monetized uploads
- Potential legal-risk content

**Rule:** AI assists production. Humans approve publication.
